# Maersk Scraper API – code examples

Examples for every Maersk endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/tracking.sh`](curl/tracking.sh) | `bash tracking.sh` |
| PHP | [`php/tracking.php`](php/tracking.php) | `php tracking.php` |
| C# | [`csharp/Tracking.cs`](csharp/Tracking.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/tracking.go`](go/tracking.go) | `go run tracking.go` |
| Java | [`java/TrackingExample.java`](java/TrackingExample.java) | `java TrackingExample.java` |
| Ruby | [`ruby/tracking.rb`](ruby/tracking.rb) | `ruby tracking.rb` |
| Node.js | [`nodejs/tracking.mjs`](nodejs/tracking.mjs) | `node tracking.mjs` |
